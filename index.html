How to Use CFGviz

01

Write Grammar Rules

Enter productions in the left panel. Format: A → BC | d. One non-terminal per line, multiple productions separated by |.

S → AB | a
A → aA | a
B → bB | b
02

Set Input String

Enter the string you want to check. The visualizer will attempt to derive it from the start symbol.

Use ε for empty string productions.

03

Choose Mode

Leftmost: Always expands the leftmost non-terminal first.

Rightmost: Always expands the rightmost non-terminal first (reverse rightmost = canonical LR).

Both: Shows both derivation types side by side.

04

Explore Results

Derivation Steps: See each substitution step with highlights.

Parse Tree: Interactive zoomable SVG tree.

Live Animation: Watch the derivation unfold in real-time.

About CFGviz

CFGviz is an educational web tool for visualizing Context-Free Grammar derivations and parse trees. Built for students of Formal Languages & Automata Theory.

✦ BFS-based derivation engine
✦ Leftmost & rightmost derivations
✦ Animated step-by-step playback
✦ Interactive SVG parse trees
✦ CNF & grammar property detection
✦ SVG export for parse trees
