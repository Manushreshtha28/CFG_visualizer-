How to Use CFGviz

01

Write Grammar Rules

Enter productions in the sidebar. Format: A → BC | d. One non-terminal per line.

S → AB | a
A → aA | a
B → bB | b
02

Set Input String

Enter the string you want to check. Use ε for empty string productions.

03

Choose Mode

Leftmost: Always expands the leftmost non-terminal first.

Rightmost: Always expands the rightmost non-terminal.

04

Explore Results

Derivation: Step-by-step with highlights.

Parse Tree: Zoomable SVG, exportable.

Live Animation: Watch it unfold with accept burst.

About CFGviz

An interactive educational web tool for visualizing Context-Free Grammar derivations and parse trees. Built for Formal Languages & Automata Theory.

✦ BFS-based derivation engine
✦ Leftmost & rightmost modes
✦ Animated step-by-step playback
✦ Interactive zoomable parse trees
✦ CNF & grammar analysis
✦ SVG export for parse trees
